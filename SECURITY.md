# Report sensitive issues privately

Please use [GitHub private vulnerability reporting](https://github.com/cylon58/omarchy-community-knowledge/security/advisories/new)
for personal-data exposure, secrets, or vulnerabilities. Do not put sensitive
details in public issues, records, or pull requests. If GitHub does not offer the
private form, withhold the sensitive details rather than posting them publicly.

Maintainers can disable the **Validate and accept data contributions** workflow
immediately while investigating. Preserve evidence privately, rotate exposed
credentials, and use reviewed forward changes or GitHub's sensitive-data removal
process as appropriate. Public history is not erased by an ordinary deletion.

Automatic contribution acceptance checks structure and policy, not whether a
suggested fix is correct, safe, or endorsed by Omarchy. Community commands are
untrusted descriptions and must never run merely because a record contains them.
